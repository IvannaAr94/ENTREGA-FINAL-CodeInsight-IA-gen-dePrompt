# CodeInsight AI - Prompt Texto → Imagen

## Herramienta utilizada

ChatGPT - Generación de imágenes

## Objetivo

Generar una representación visual del funcionamiento de CodeInsight AI y del proceso de análisis técnico de código mediante Inteligencia Artificial.

## Prompt optimizado

Create a professional technology infographic representing **CodeInsight AI**, an artificial intelligence assistant for web code analysis.

The composition should show a web application source code interface on the left, connected through an artificial intelligence processing system in the center, and analysis results on the right.

Represent the following analysis areas clearly:

- Code Quality
- Security
- Performance
- Maintainability
- Documentation

Show a clear workflow:

Source Code → AI Analysis → Technical Findings → Prioritized Improvements

Include visual indicators representing High, Medium and Low priority findings.

Style requirements:

- professional software engineering dashboard
- modern and minimalist interface
- clean visual hierarchy
- white or very light background
- purple and blue technological accents
- subtle artificial intelligence elements
- readable interface components
- professional academic presentation
- landscape format
- no unnecessary decorative objects
- no company logos
- no real people
- avoid excessive text inside the image

The final image should visually communicate how artificial intelligence assists developers in reviewing code and transforming technical findings into prioritized improvements.
